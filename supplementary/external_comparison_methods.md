# External medical-benchmark comparison: methods

To place Growth-MedQA performance in context, the same models were evaluated on a fixed-seed comparator of general medical questions drawn from four external benchmarks (MedQA test, MedMCQA validation, and expert-labeled PubMedQA PQA-L), under the identical prompt and scoring policy used for Growth-MedQA.

- Sampling: a fixed random seed selected an equal-sized sample per external benchmark, so the comparator is reproducible.
- Overlap control: each candidate external item was hashed on its normalized question and option text and excluded if it collided with any Growth-MedQA item, so the comparator shares no question-option overlap with Growth-MedQA.
- Pediatric-content exclusion: items with pediatric content were removed from the external comparator so that it measures general (non-pediatric) medical competence.
- Correlation: model rankings on the external macro-average and on Growth-MedQA were compared with the Spearman rank correlation.

Per-benchmark model accuracies for the current ten-model primary set are regenerated by the analysis code; the archived comparator analysis was computed on an earlier model set and is not reproduced here to avoid mixing model configurations.
