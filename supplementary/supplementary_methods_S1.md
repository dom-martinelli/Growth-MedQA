# Supplementary Methods S1. Label construction and validation

We constructed a manually adjudicated, expert-explanation-enriched reference set from sources with structured teaching-point explanations, labeled in three passes: initial assignment against written scope rules, structured review of boundary cases with item-level notes, and final reconciliation. These manual labels are the reference standard against which the automated labels were validated. Because a single reference labeling was produced rather than independent double-labeling by multiple clinicians, agreement figures characterize automated-versus-reference concordance, not multi-rater inter-clinician reliability.

The reference labels seeded a few-shot labeling classifier: a fixed set of worked demonstrations drawn from the manual set, appended to a seed prompt whose task instructions were left unchanged. Inputs were the question stem, answer options, keyed answer, and, where available, the expert explanation. Outputs were the growth-relevance label (a binary include/exclude judgment of whether growth is part of the tested reasoning), one or more USMLE physician competencies labeled directly against the 2020 USMLE outline, and a concise growth-concept statement. Growth-topic categories were assigned in a separate ICPED and ABP pass. Because these fields place an item in a slice and never determine its answer, a model that participated in labeling could affect only which slice an item fell into, not whether any model answered it correctly.

Growth-relevance of named conditions was cross-referenced to MONDO, OMIM, and Orphanet identifiers, with growth-relevance grounded in a curated disease-phenotype annotation descending from Growth abnormality (HP:0001507) in the Human Phenotype Ontology. Validation of the automated labels against the manually adjudicated reference set is summarized in the main text.
